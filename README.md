# Portfólio de engenharia

**Português** | [English](README.en.md)

Ferramentas que desenvolvi no meu trabalho de engenharia mecânica em projetos de
infraestrutura hídrica: drenagem urbana, saneamento e geração hidrelétrica.
Cada uma nasceu de uma tarefa recorrente de escritório, não de um exercício de
programação. O objetivo é sempre o mesmo: tirar da rotina o trabalho repetitivo
e deixar a atenção para a decisão de engenharia.

| Projeto | O que faz | Ferramentas |
| --- | --- | --- |
| [Extrator de Curvas](extrator-de-curvas/README.md) | Aplicativo de desktop que transforma curvas de gráficos (catálogos em PDF, imagens escaneadas) em tabelas de dados. | Python, PySide6, NumPy, SciPy |
| [Seletor de bombas](seletor-bombas/README.md) | Seleciona bombas centrífugas para uma estação com rotação variável e verifica potência e NPSH. Gera um relatório em Excel. | Python, pandas, NumPy, openpyxl |
| [Curvas de bombas](curvas-bombas/README.md) | Utilitário simples que cruza curvas de bombas com curvas de sistema e padroniza a tabela e o gráfico de pontos de operação. | Python, pandas, Shapely, Matplotlib |
| [Lista de materiais em LaTeX](lista-materiais-latex/README.md) | Monta a lista de materiais de uma emissão, com capa, sumário e fichas por família, em PDF. | Python, Excel, LaTeX |
| [Doc2MD](doc2md/README.md) | Converte um acervo de normas e referências técnicas em PDF para Markdown que uma IA consegue consultar sem perder a rastreabilidade. | Python, Docling, OCRmyPDF, Tesseract |


## Sobre os dados

Os bancos, catálogos e casos de exemplo são sintéticos ou descaracterizados.
Nenhum dado de cliente, de contrato ou de banco corporativo está neste
repositório. As normas técnicas citadas no Doc2MD aparecem apenas pela
identificação; nenhum documento normativo é redistribuído.
