# Engineering portfolio

[Português](README.md) | **English**

Tools I built for my own mechanical engineering work on water infrastructure
projects: urban drainage, sanitation and hydropower. Each one started as a
recurring office task, not as a programming exercise. The goal is always the
same: take the repetitive work out of the routine and keep attention on the
engineering decision.

| Project | What it does | Tools |
| --- | --- | --- |
| [Curve Extractor](extrator-de-curvas/README.en.md) | Desktop app that turns chart curves (PDF catalogues, scanned images) into data tables. | Python, PySide6, NumPy, SciPy |
| [Pump selector](seletor-bombas/README.en.md) | Selects centrifugal pumps for a variable-speed station and checks power and NPSH. Writes an Excel report. | Python, pandas, NumPy, openpyxl |
| [Pump curves](curvas-bombas/README.en.md) | Small utility that intersects pump curves with system curves and standardises the operating-point table and chart. | Python, pandas, Shapely, Matplotlib |
| [LaTeX bill of materials](lista-materiais-latex/README.en.md) | Builds the bill of materials for a document issue as a PDF, with cover, table of contents and one sheet per family. | Python, Excel, LaTeX |
| [Doc2MD](doc2md/README.en.md) | Converts a collection of technical standards and references from PDF into Markdown that an AI can query without losing traceability. | Python, Docling, OCRmyPDF, Tesseract |

## About the data

The databases, catalogues and example cases are synthetic or de-identified.
No client, contract or corporate database data is included. The standards
mentioned in Doc2MD are cited by identification only; no standard is
redistributed.
